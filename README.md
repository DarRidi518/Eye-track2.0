# Eye-track2.0

Система мониторинга состояния водителя на базе ИИ, предотвращающая ДТП из-за засыпания за рулём.

## 🎯 Описание
Приложение в реальном времени отслеживает состояние глаз водителя с помощью нейросети MediaPipe Face Mesh. При обнаружении засыпания выводится предупреждение, "а при игнорировании инициируется протокол экстренной остановки".

## ✨ Особенности
- 🧠 **ИИ-детекция**: MediaPipe Face Mesh (468 точек лица).
- 🌙 **Ночной режим**: CLAHE-фильтрация для работы в темноте. (разработка)
- 📊 **Анализ EAR**: точное математическое определение состояния глаз.


## 🛠 Технологии
Python 3, OpenCV, MediaPipe, NumPy
